# Explainable AI Loan Risk Assessment System

Predicts loan default risk using the LendingClub dataset, with SHAP-based explainability.

## Dataset
LendingClub Accepted Loans (2007-2018). Download from Kaggle and place
`accepted_2007_to_2018Q4.csv.gz` in the project root before running notebooks.

## Status
Currently in EDA phase.
